# WIZZY FOLD — Fashion Store Portfolio

A four-page, responsive clothing-brand concept store built with plain HTML, CSS, and JavaScript. The visual direction is an editorial streetwear label: warm paper, ink-black typography, acid-lime accents, oversized type, asymmetrical image layouts, and small studio-style details.

## Pages
- `index.html` — editorial homepage, featured pieces, brand statement, newsletter demo
- `collection.html` — product grid, category filters, price sorting, and an in-memory demo bag
- `story.html` — brand philosophy and values
- `contact.html` — studio contact information and a local-only demo form

## Structure
- `assets/css/global.css` — shared design tokens, typography, navigation, cards, buttons, footer, responsive foundations
- `assets/css/home.css` — homepage-specific styling
- `assets/css/collection.css` — collection and demo bag styling
- `assets/css/story.css` — editorial story layout
- `assets/css/contact.css` — contact and form layout
- `assets/js/main.js` — mobile navigation, collection filters, sorting, demo bag, local form confirmations

## Run locally
Open `index.html` in a browser or use a simple static server. No package install or build step is required.

## Notes
This is a portfolio/demo experience, not a production commerce system. Product names, prices in Zambian kwacha, contact details, and brand content are illustrative placeholders. Product photos load from Unsplash and require an internet connection. The bag is in-memory only; there is no checkout, payment processing, account system, order storage, or real newsletter/contact delivery.
